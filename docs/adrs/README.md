# Architecture Decision Records (ADRs)

This directory tracks significant design decisions, plans, and implementation
strategies for the Pika power monitor project. Each ADR captures the context,
decision, and consequences so future contributors understand *why* things are
the way they are.

## Format

Each ADR is a numbered Markdown file: `NNNN-short-title.md`.
