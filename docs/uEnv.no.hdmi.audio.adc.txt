# This is the /boot/uEnv.txt file for the BBB
# This file will disable HDMI, Audio, and ADC
# This is needed in order to free up enough pins for the PRU to use
# pin outs on the BBB https://vadl.github.io/beagleboneblack/2016/07/29/setting-up-bbb-gpio


# By disabling video, audio, and ADC, you've freed up several high-demand pins—specifically the "LCD Data" pins on the P8 header and the analog inputs on P9.
# 1. Newly Freed Pins (Formerly Reserved) 
# Video (HDMI/LCD): Disabling video frees up P8_27 through P8_46. These are the LCD data pins (Mode 0: lcd_data0 to lcd_data15).
# Audio: Frees up P9_25, P9_28, P9_29, and P9_31.
# ADC: Frees up P9_33 through P9_40. Note: These are strictly 1.8V analog pins and cannot be used for 3.3V digital I/O. 


# 2. PRU-Reachable Pins (Fast I/O) 
# The PRUs (Programmable Real-Time Units) can access pins in two ways. "Enhanced GPIO" 
# (using __R30 for output and __R31 for input) is the fastest, providing deterministic, 
# single-cycle access. 
#
# Header Pin | PRU & Register Bit | Former Use (Now Free)
# -----------|--------------------|----------------------
# P8_45      | PRU1, Bit 0        | Video (LCD Data)
# P8_46      | PRU1, Bit 1        | Video (LCD Data)
# P8_43      | PRU1, Bit 2        | Video (LCD Data)
# P8_44      | PRU1, Bit 3        | Video (LCD Data)
# P8_41      | PRU1, Bit 4        | Video (LCD Data)
# P8_42      | PRU1, Bit 5        | Video (LCD Data)
# P8_39      | PRU1, Bit 6        | Video (LCD Data)
# P8_40      | PRU1, Bit 7        | Video (LCD Data)
# P9_31      | PRU0, Bit 0        | Audio
# P9_29      | PRU0, Bit 1        | Audio
# P9_30      | PRU0, Bit 2        | Audio
# P9_28      | PRU0, Bit 3        | Audio
